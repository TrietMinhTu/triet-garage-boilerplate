Findings for the BA meeting

Surfaced while reviewing the live build against this mockup — worth confirming before the requirements doc is finalized.

Flag

Missing-photo state is undefined

The current card renders <img src={member.image}> with no fallback. Proposing the initials-circle treatment shown above — reuses the existing avatar ring, no new asset needed.

Flag

Sign-in field is labeled "Username"

The input still takes an email address (type email, validated as one) — the label just says "Username." Worth confirming with Kareem whether the field itself is changing, or the label should read "Email."

Flag

"Create account" link only appears after a failed attempt

A first-time visitor who hasn't tried signing in yet has no way to find the sign-up page from this screen. Worth confirming this is intentional.

Flag

"Triet Tan" should read "Triet Tu"

Placeholder data has a typo in the PM's surname — content fix, not a design one, flagging here so it isn't lost.
