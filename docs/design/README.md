# UX design mockups

Static design reference docs — open directly in a browser, not part of the app build.

## bootstrap-restyle-mockup.html

Wireframe for the "Bootstrap Restyling" login + team page card. Reconstructs both screens
from the live `feature/restyleSignIn` implementation, documents the existing long-blurb
truncation behaviour, and proposes a missing-photo fallback state that isn't handled in the
current build. Includes open findings flagged for BA review (Kareem).

Prepared by Michael Fajardo (UX).
